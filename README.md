# Pharma Check AI 
Pharma Check AI adalah aplikasi berbasis web yang dirancang untuk membantu mahasiswa farmasi dan tenaga kesehatan dalam menganalisis kandungan obat serta potensi interaksi antar obat secara cepat dan cerdas.

#Fitur Utama
Drug Interaction Checker  : Menganalisis apakah dua atau lebih obat aman jika dikonsumsi bersamaan.
Content Analysis          : Memberikan penjelasan mendalam tentang zat aktif dalam suatu produk farmasi.
AI-Powered                : Menggunakan Google Gemini API untuk memberikan analisis berbasis data medis terkini.

#Teknologi yang Digunakan
Python     : Bahasa pemrograman utama untuk logika sistem.
Streamlit  : Framework untuk membangun antarmuka web yang interaktif.
Gemini API : "Otak" AI yang memproses informasi farmakologis.
GitHub     : Tempat penyimpanan kode dan kolaborasi.

*Catatan: Aplikasi ini dibuat untuk tujuan edukasi dan bantuan referensi. Selalu konsultasikan hasil analisis dengan apoteker atau dokter profesional.*
